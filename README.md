# 🚍 Jeepney Route System

A **Jeepney Route System** designed to help commuters from different places efficiently map and manage jeepney routes across Batangas City.  
This system aims to make local transportation smarter, more accessible, and better organized using technology.

---

## 🗺️ Overview

The **Jeepney Route System** provides an easy-to-use platform for finding and managing jeepney routes.  
It can show route details, travel distances, possible transfer points between jeepney lines.

This project was created to address the lack of digital tools for public jeepney route navigation and management in Batangas City.

---

## ✨ Features

- 🧭 **Route Finder** – Displays possible jeepney routes between two locations.  
- 📍 **Interactive Map** – Visualize routes on a map for better navigation.  
- 🧮 **Distance Estimation** – Uses coordinate data or preset values to estimate travel distance.  
- 🖥️ **User Interface** – Clean and simple UI for easy use by commuters and admins alike.
