# 🚍 Jeepney Route System

A **Jeepney Route System** designed to help commuters from different places efficiently map and manage jeepney routes across Batangas City.  
This system aims to make local transportation smarter, more accessible, and better organized using technology.

---

## 🗺️ Overview

The **Jeepney Route System** provides an easy-to-use platform for finding and managing jeepney routes.  
It can show route details, travel distances, possible transfer points between jeepney lines.

This project was created to address the lack of digital tools for public jeepney route navigation and management in Batangas City.

---

## ✨ Features

- 🧭 **Route Finder** – Displays possible jeepney routes between two locations.  
- 📍 **Interactive Map** – Visualize routes on a map for better navigation.  
- 🧮 **Distance Estimation** – Uses coordinate data or preset values to estimate travel distance.  
- 🖥️ **User Interface** – Clean and simple UI for easy use by commuters and admins alike.

---

## 🎯 Project Goal

Our goal is to develop a **digital platform** that modernizes the way people access jeepney routes and information.  
By integrating technology with traditional transportation, we aim to:

- Help commuters easily find jeepney routes and directions.  
- Simplify route management for transport administrators.  
- Promote smarter, more efficient, and organized travel experiences.  
- Support the preservation and modernization of the Filipino jeepney culture.

---

## ⚙️ How It Works

1. **Data Collection & Mapping**  
   Collect data on existing jeepney routes, terminals, and stops within Batangas City.  
   Use mapping APIs (e.g., Google Maps or OpenStreetMap) to visualize and connect these routes.

2. **Route Finder**  
   Allow users to input their **starting point** and **destination**.  
   The system displays possible jeepney routes, including any required transfers.

3. **Interactive Map**  
   Integrate an interactive map for route visualization, showing jeepney lines and landmarks for easy navigation.

4. **Distance Estimation**  
   Use coordinate data or preset route values to estimate travel distances and potential travel times.

5. **User Interface**  
   Design a clean, simple, and mobile-friendly UI that’s accessible to both commuters and transport administrators.

---

## 🇵🇭 Why This Project Matters

In the Philippines, there is still **low focus on improving the local transportation system**, especially when it comes to digital route management.  
Commuters often depend on word-of-mouth directions or manual observation to find their way — leading to confusion and wasted time.

This project aims to **bridge that gap** by providing a digital solution that supports the traditional jeepney system while improving accessibility and efficiency.

With the Jeepney Route System, we strive to:
- Make public transportation information **available and reliable**.  
- **Assist commuters** in planning efficient trips.  
- **Empower local authorities** to manage jeepney routes more effectively.  
- Encourage **technological innovation** in traditional Filipino transportation.
